# 项目与目录约定

项目保持简单、按职责分层：

```text
configs/     # 可提交的实验配置
src/         # 数据、模型、训练和评估实现
scripts/     # train.sh、eval.sh、common.sh
outputs/     # 每个实验独立的产物目录
logs/        # 所有运行日志
tests/       # 快速测试（按需）
```

- 不在训练代码中硬编码数据路径、GPU、随机种子或超参数；这些来自配置或脚本参数。
- `README.md` 写清环境安装、最小训练命令和最小评估命令。
- `pyproject.toml` 与 `uv.lock` 必须提交；原始数据、权重、缓存和运行日志不得提交。
- 新增框架或目录前，先更新本文件的目录说明。
